# EstateHub: The Modern Solution for Estate Management

## Product Manual & Feature Overview

---

### 1. Introduction: Simplify Your Estate Management

Welcome to **EstateHub**, the all-in-one application designed to modernize and streamline the management of residential and commercial estates. In today's fast-paced world, managing finances, personnel, and resident services can be complex and time-consuming. EstateHub replaces cumbersome spreadsheets and outdated software with a single, intuitive, and powerful platform.

Our application empowers administrators with robust financial tools, enhances security with a modern QR-based pass system, and provides a consistent, easy-to-use portal for residents, staff, and contractors.

**Why choose EstateHub?**
*   **Centralized Control**: Manage all aspects of your estate from a single, powerful dashboard.
*   **Interactive Dashboards**: All user portals feature interactive Key Performance Indicators (KPIs) with drill-down capabilities for detailed insights.
*   **Financial Transparency**: Automate maintenance calculations, apply fines, and view a detailed double-entry style cashbook for a complete financial overview.
*   **Enhanced Security**: Implement a secure and efficient QR code-based system for resident, vendor, and staff access.
*   **Role-Based Access**: Provide tailored portals for Admins, Apartment Owners, Contractors, and Security personnel, ensuring everyone has the tools they need.
*   **Fully Customizable**: From application branding to individual page layouts, EstateHub adapts to your society's unique requirements.

### 2. Key Features at a Glance

*   **Comprehensive KPI Dashboards**: At-a-glance, interactive KPIs on every portal for financial health, user management, and pending actions.
*   **Automated Financials**: Sophisticated maintenance calculation based on apartment size, with automatic late fees and daily fines.
*   **Integrated Cashbook**: A complete, double-entry style cashbook for a full financial overview of receipts and payments.
*   **Intelligent Financial Forms**: Streamlined forms for creating new receipts and expenses with cascading dropdowns that guide account and entity selection.
*   **QR Code Pass System**: Secure, scannable QR codes for every user, verifiable through the Security portal.
*   **Role-Based User Directory**: A central user directory accessible to all, with appropriate permissions for each role.
*   **Customizable Page Layouts**: Admins can visually design the page layouts for *any* user role, creating the perfect experience for their community.
*   **Entity Enrollment & Management**: Easily enroll new users one-by-one or import hundreds at once via CSV.

### 3. User Portals: A Tailored Experience for Everyone

EstateHub provides four distinct portals, each designed for a specific role, offering a consistent and intuitive user experience.

#### A. The Admin Portal: Your Command Center

The Admin portal offers complete control over the entire estate.

*   **Dashboard**: The first thing you see is a powerful dashboard with interactive KPIs. Click on any metric—like "Apartments with Dues" or "Pending Receipts"—to instantly drill down into a detailed list or report.
    `[Screenshot of the Admin Dashboard showing clickable KPI cards]`
*   **Cashbook**: A professional-grade, double-entry style cashbook provides a detailed ledger of all financial transactions, separating receipts and payments for ultimate clarity.
    `[Screenshot of the Cashbook page with transaction rows]`
*   **Receipts & Expenses**: View complete logs of all payments and expenses. Intelligent forms make it easy to create new entries, guiding you to select the correct account and entity.
    `[Screenshot of the New Receipt form showing cascading dropdowns]`
*   **Users & Enrollment**: Manage a comprehensive list of all users. Add new users individually or perform a bulk import via CSV.
*   **Settings**: A dedicated settings area with multiple tabs:
    *   **Global Settings**: Customize the society name, logo, and login page branding.
    *   **Admin Settings**: Manage financial rates for maintenance, contractor passes, and late fees.
    *   **Accounts**: Create and manage financial accounts, set depreciation rates, and define calculation start dates for arrears.
    *   **Personnel Settings**: Manage work shifts for security staff.
    `[Screenshot of the Admin Settings page with the Accounts tab selected]`
*   **Layout Customization**: Uniquely, Admins can visually design the page layouts for *any* user role. Drag and drop KPI cards to create the perfect dashboard or utility page for your residents, security, or contractors.
    `[Screenshot of the 'Customize' page showing the drag-and-drop interface]`

#### B. The Apartment Owner Portal: Clarity and Convenience

Residents get a clean, simple portal to manage their finances and access.

*   **Personal Dashboard**: A welcoming dashboard displays interactive KPIs for their financial status (Dues, Total Charges) and community metrics (total residents, contractors). Clicking a KPI drills down to a detailed view. It also shows a summary of upcoming events.
    `[Screenshot of the Apartment Owner Dashboard with KPIs and Events]`
*   **Charges & Payment History**: Accessible via the dashboard drill-down, this page provides a detailed, itemized ledger showing exactly how their balance is calculated, including charges, fines, and payments.
    `[Screenshot of the 'Charges & Payment History' card with debits, credits, and a running balance]`
*   **User Directory**: View a directory of other residents, contractors, and security staff.
*   **Personal Pass & Settings**: View their personal QR code pass and update their contact information or password.

#### C. The Security Portal: Efficient and Secure

The Security portal is built for speed and efficiency, focusing on core security tasks.

*   **Dashboard**: A focused dashboard featuring the **Scan Pass** module as the primary tool for instant QR code evaluation.
    `[Screenshot of the Security Dashboard showing the prominent Scan Card]`
*   **Attendance**: A dedicated page to view assigned shift information and use "Clock In" / "Clock Out" buttons to log shifts.
*   **User Directory**: Access a read-only directory of all society members for quick reference.
*   **Personal Pass**: Security staff also have their own QR code for identification and can view their settings.

#### D. The Contractor Portal: Simple Access Management

Vendors and contractors have a straightforward portal to manage their access and payments.

*   **Dashboard**: An interactive dashboard shows KPIs for their total payments and the number of apartments in the society. Clicking a KPI navigates to the relevant detailed page.
    `[Screenshot of the Contractor Dashboard with KPIs]`
*   **Payment History**: A log of all pass purchase payments, accessible from the dashboard.
*   **Personal Pass**: Shows their service type and a QR code for their current vendor pass.
